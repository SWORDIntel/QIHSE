# QIHSE licence migration — 2026-10-17

First-party QIHSE material in distributions adopting this revision is offered under [SRSL-1.1](../LICENSE). Previous SRSL-1.0 grants remain valid for copies already issued under that version. Its original text is archived in [LICENSES/SRSL-1.0.txt](../LICENSES/SRSL-1.0.txt).

This update is confined to first-party licence references, release metadata and documentation. The vendored Tree-sitter source and any other third-party components retain their respective existing licences; SRSL does not override those rights. Distribution teams must audit all dependencies before making ownership or relicensing claims.

The new terms restrict for-profit internal uses and reserve ML source-training rights (with mandatory statutory exceptions) but do not add runtime DRM, account registration or telemetry. Commercial rights require a separately signed Commercial Agreement, and 50% profit participation is a negotiable proposal, not automatic breach damages.

This update does not alter runtime logic, wire formats, persisted data, third-party notices, or test acceptance thresholds. UK IP counsel should review the legal terms before relying on them for enforcement. See [the licence](../LICENSE) for controlling terms.
